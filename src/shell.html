                Defaults / Element typography
              

              
Typography specimen

              

                A representative long-form document. Adjust defaults in the sidebar and review the
                full reading rhythm here.
              

            

            

              

                The quiet architecture of everyday things
              

              

                Good typography rarely asks to be noticed. It gives shape to thought, creates
                hierarchy without noise, and lets a reader move through a page without wondering
                where to look next. This specimen gathers the ordinary elements of a long document
                into one continuous reading experience.
              

              

                Inline language matters too: text may be
                strongly emphasized, gently stressed, linked to
                a related source, or marked with
                inline code. Each treatment should remain distinct without disturbing the line.
              

              
              

              

                A useful hierarchy
              

              

                Headings divide an argument into meaningful parts. Their size, weight, and spacing
                should work together: scale establishes rank, while surrounding space explains
                relationships.
              


              

                Unordered observations

    • 
                
  • 
                  Lists should preserve the same rhythm as neighboring paragraphs.
                
    • 
                
  • 
                  Local block styling can still make a deliberate exception.

Measure

                

                  The readable width of a line of text, usually judged by characters per line.
                

                

                  Rhythm
                

                

                  The repeated vertical intervals that help separate and connect elements.
                

                

                  Hierarchy
                

                

                  The visual ordering that communicates which ideas lead and which support them.

                  System / Responsive design
                

                
Breakpoints

                

                  Author mobile-first, then add overrides at named minimum widths. Device groups
                  organize the editor selector; breakpoint names remain portable Tailwind variants.
                

              

              
            


            

              !
              Breakpoint widths must increase from sm through 2xl.
            

            


            

              
            

          


          
          

            

              

                

                  System / Page layout
                

                
Container widths

                

                  Groups marked as containers choose a semantic width; the measurements live here.
                  Authors can pick Content or Wide, but cannot enter one-off widths on a block.
                

              

              
            


            


            

              
            


            

              
Block behavior

              

                Marking a Group as a Container constrains that Group itself. Its children keep their
                normal layout, and the document stores only the Content or Wide role.
